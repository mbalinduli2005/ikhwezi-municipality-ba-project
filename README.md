# ikhwezi-municipality-ba-project
BA Project-Citizen Portal &amp; Case Management for Ikhwezi District Municipality | Mancosa
Role: Business Analyst | Mancosa

Problem:
Manual paper logs + spreadsheets. Citizens in Ward 4 travel hours to report a burst pipe, get no reference number, no updates for weeks. Front desk has no tracking. Billing is inaccurate.

Elicitation:
Interviewed Sipho Nkosi (Resident, Ward 4) and Adrian Chetty (Front-desk Clerk).

Requirements:
User stories + acceptance criteria for Citizen, Clerk, Manager, Technician, Billing Officer, Ward Councillor.

Process:
5-phase lifecycle: Log > Intake > Assign > Resolve > Notify + Bill correctly

Data Evidence - Ward 4 (Oct 2026, n=20):
- WaterLeak: 7, Pothole: 5, BillingError: 3, Electricity: 2, Flooding: 2, SafetyRisk: 1
- Water + Pothole = 60% of complaints

Recommendation:
Custom Mobile Portal (USSD/SMS + CRM), R400k, 6 months, offline mode. Pilot in Ward 4 first using Agile.
